## 推荐阅读顺序

1. 先读 `2023_ActaOpticaSinica_fiber_laser_CBC_active_phase_control_review.pdf` 和 `2009_ChineseJournalLasers_active_phase_control_fiber_laser_CBC.pdf`，建立主动相位控制整体框架。
2. 再读 `2010_ActaPhysicaSinica_high_precision_phase_control_CBC_SPGD.pdf`、`2014_ActaOpticaSinica_adaptive_SPGD_CBC.pdf` 和 `2024_InfraredLaserEngineering_staged_adaptive_SPGD_CBC.pdf`，理解 SPGD 从基础控制到自适应改进的发展。
3. 接着读 `2010_ChineseJournalLasers_two_fiber_amplifier_CBC_SPGD.pdf` 和 `2012_ChineseJournalLasers_two_nanosecond_pulse_fiber_lasers_CBC_SPGD.pdf`，补双光束/两路系统实验背景。
4. 然后读 `2021_HighPowerLaserParticleBeams_deep_learning_wavefront_sensing_review.pdf`、`2023_ChineseJournalLasers_machine_learning_laser_adaptive_optics_review.pdf` 和 `2024_ChineseJournalLasers_attention_open_loop_slope_prediction_AO.pdf`，支撑深度学习相位/波前估计与预测路线。
5. 最后读 `2024_ChineseJournalLasers_eight_channel_ultrafast_fiber_laser_CBC.pdf`，为后续多路扩展做铺垫。

## 与当前课题的对应关系

你的新路线是：

```text
远场序列 -> CNN + LSTM -> 预测未来相位 -> 闭环控制 -> 替代部分 SPGD
```

这些中文论文主要支撑其中三部分：

- **传统控制基线**：SPGD、多阶段 SPGD、主动相位控制。
- **物理应用背景**：光纤激光相干合成、多路相控阵、超快激光相干合成。
- **评价指标来源**：远场能量集中度、闭环收敛速度、相位锁定效果、合成效率。
- **创新性论证**：机器学习自适应光学、深度学习波前传感、开环预测控制。
