# 基于傅里叶光学约束的七光束相干合成相位误差反演方法研究

版本：v0.1 初稿  
日期：2026-06-10  
状态：阶段性论文草稿，基于当前已完成实验结果整理；部分补偿指标和 Cycle 25 原始结果归档仍需后续补齐。

## 摘要

相干光束合成（coherent beam combining, CBC）能够通过多路激光相干叠加突破单路激光功率限制，但合成效率和远场能量集中度对各通道相对相位误差高度敏感。传统随机并行梯度下降（SPGD）等闭环优化方法不需要显式测量相位，但通常需要多步迭代，难以在快速相位扰动下兼顾响应速度和控制精度。本文面向七光束六边形阵列相干合成系统，研究由单帧远场光强图像反演外圈六路相对相位误差的深度学习方法。项目首先建立双光束低维验证链路，再扩展到七光束主系统；相位标签采用 `sin(phi)` 与 `cos(phi)` 周期编码，避免相位边界不连续。为提升预测结果的物理可信度，本文将七光束近场复振幅到远场强度的傅里叶传播关系引入训练损失，构建相位监督误差与远场一致性误差的联合优化框架。实验结果表明，在七光束干净数据集上，普通 CNN 的相位 RMSE 为 `1.026976 rad`，首版物理约束 CNN 将 RMSE 小幅降至 `1.022686 rad`，并降低远场重建误差。进一步引入残差网络和最佳验证 checkpoint 策略后，`residual_cnn` 的最佳 checkpoint 测试 RMSE 达到 `0.992071 rad`；将残差网络与物理约束结合后，当前最优 `lambda_phy=0.05` checkpoint 测试 RMSE 为 `0.983128 rad`。在补偿效果评估中，首版物理约束 CNN 相比普通 CNN 将主瓣能量占比从 `0.519307` 提高到 `0.521546`，Strehl 比从 `0.647172` 提高到 `0.653564`，合成效率从 `0.786023` 提高到 `0.789644`。此外，本文还记录了自研轻量网络 `cbc_lite_cnn` 与周期相位损失的负结果：三种损失下最佳 RMSE 均未超过残差物理约束路线。当前结果说明，七光束 CBC 相位反演显著难于双光束任务，最佳 checkpoint 策略、残差特征提取和傅里叶物理约束能够带来阶段性收益，但相对国际文献中约 `0.239 rad` 的误差量级仍有明显差距。后续工作将优先在残差物理约束路线中继续验证周期损失、数据规模扩展和离焦强度图输入。

**关键词**：相干光束合成；相位误差反演；傅里叶光学；物理约束深度学习；卷积神经网络；七光束阵列

## 1. 引言

高功率光纤激光系统受到单根光纤非线性效应、热效应和损伤阈值等因素限制，难以仅依靠单路放大持续提升输出功率。相干光束合成通过控制多路激光之间的相位关系，使远场主瓣相干增强，是获得高亮度、高功率激光输出的重要技术路线之一。对于多路 CBC 系统而言，若各通道存在相位失配，远场能量会从中心主瓣泄露到旁瓣区域，导致 Strehl 比、主瓣能量占比和合成效率下降。因此，快速、准确地估计并补偿各通道相位误差，是 CBC 系统走向工程应用的核心问题。

现有 CBC 相位控制方法大体可分为直接相位检测和间接闭环优化两类。直接相位检测需要额外干涉测量或传感结构，系统复杂度和标定要求较高。SPGD 等间接优化方法只需远场强度评价函数，结构简单、工程适应性较强，但通常依赖多次扰动和迭代搜索；当相位噪声变化较快或通道数量增加时，迭代收敛速度可能成为瓶颈。近年来，深度学习为“从可观测强度图像反推不可直接观测相位状态”提供了新的可能。Hou 等将卷积神经网络用于拼接孔径 CBC 相位控制，证明非焦平面强度图能够包含更丰富的相位信息。Mills 等使用深度学习从多芯阵列焦平面强度图预测相位图，并用于单步相位优化和光束整形。Xie 等进一步在七光束实验系统中实现了单步相位识别和闭环相位锁定，并指出周期相位损失和焦前图像对提升识别能力具有重要作用。

本文工作在上述研究基础上，面向七光束相干合成相位误差反演建立一套可复现实验链路。与已有文献不同，本文当前阶段重点不是直接复现某一网络结构，而是在自建傅里叶仿真数据集上比较普通 CNN、物理约束 CNN、残差 CNN、残差物理约束 CNN 以及周期损失/轻量网络探索结果。本文强调两个问题：第一，预测相位误差本身是否足够准确；第二，预测结果是否能够在下游远场补偿指标中转化为主瓣能量、Strehl 比和合成效率提升。当前结果尚未达到文献最好水平，但形成了从数据生成、模型训练、物理一致性约束、鲁棒性评估到补偿指标计算的完整研究框架。

本文主要贡献如下：

1. 建立了双光束低维验证与七光束主系统相结合的 CBC 相位反演仿真平台，七光束系统以中心光束为参考，反演外圈六路相对相位。
2. 采用 `sin/cos` 周期编码和周期 RMSE 评价，避免相位边界跳变导致的误差统计失真。
3. 将七光束傅里叶传播模型引入训练损失，构建 `L_phase + lambda_phy * L_farfield` 的物理约束 CNN。
4. 通过残差结构、最佳验证 checkpoint 和物理约束组合，将七光束测试 RMSE 从普通 CNN 的 `1.026976 rad` 降至当前最优 `0.983128 rad`。
5. 系统记录了探测器噪声、振幅失配、位置偏移、主瓣能量、Strehl 比、合成效率等多种指标，使模型评价不局限于相位 RMSE。
6. 如实给出 `cbc_lite_cnn` 与周期损失探索的负结果，为后续模型选择和论文论证提供消融依据。

## 2. 相关工作

### 2.1 传统 CBC 相位控制

CBC 系统中的相位控制长期依赖相位调制器、远场探测器和反馈控制算法。SPGD 方法通过随机扰动各通道相位并根据评价函数变化方向更新控制量，不要求显式相位测量，因而在光纤阵列相干合成中得到广泛研究。国内相关研究围绕主动相位控制、随机扰动优化、自适应 SPGD、多级相控阵列和高功率光纤激光相干合成等方向展开，说明 SPGD 类方法具有较强工程生命力。然而，SPGD 的迭代特性也意味着控制速度与通道数量、扰动强度、评价函数噪声和执行器响应密切相关。当系统从双光束扩展到七光束、十九光束甚至更大阵列时，单纯依靠多步迭代可能难以满足高速相位扰动场景。

### 2.2 深度学习相位估计

深度学习方法试图直接学习强度图像与相位误差之间的非线性映射。Hou 等在拼接孔径 CBC 系统中使用 CNN 从非焦平面强度分布估计相位误差，并指出非焦平面图像相比焦平面图像能缓解相位状态碰撞问题。Mills 等将条件生成网络用于十九芯 CBC 单步相位优化，从强度图预测相位图并进一步判断目标光场可达性。Xie 等在 2024 年 Scientific Reports 中构建七光束实验系统，采用 MobileNetV3-Small 和周期相位损失进行单步相位识别，实现实时闭环相位锁定和定制光束整形。上述研究共同说明，强度图像可以作为隐藏相位状态的代理观测，深度学习有潜力把多步相位优化转化为单步推理。

### 2.3 物理约束深度学习

纯数据驱动模型容易学习训练集中的统计相关性，却不一定满足光学传播规律。对于 CBC 相位反演问题，网络输出的相位预测不仅应接近真实标签，还应能够重建与输入图像一致的远场强度分布。物理约束深度学习的思想是把已知物理模型纳入损失函数、网络结构或后处理流程，使模型学习受到物理规律约束。本文采用的策略是在监督相位损失之外，使用七光束傅里叶光学模型从预测相位重建远场强度，并与输入远场图像计算一致性误差。该方法不改变数据标签格式，但能把“相位预测是否物理可解释”纳入训练目标。

## 3. 七光束相干合成模型与数据集

### 3.1 七光束阵列结构

本文主系统采用七光束六边形阵列：一束中心参考光束位于阵列中心，六束外圈光束等角度排布。中心光束相位固定为参考相位 `0`，网络需要预测外圈六路光束相对中心光束的相位误差：

```text
phi = [phi_1, phi_2, phi_3, phi_4, phi_5, phi_6]
```

每一路相位均为周期变量，范围为 `[-pi, pi]`。为避免相位在 `pi` 与 `-pi` 附近出现标签不连续，本文将每一路相位编码为：

```text
y_i = [sin(phi_i), cos(phi_i)]
```

因此七光束任务的网络输出维度为 `12`。

### 3.2 傅里叶远场仿真

每一路近场光束用高斯光束近似。设第 `k` 路光束的振幅为 `A_k(x,y)`，中心位置为 `(x_k, y_k)`，相位为 `phi_k`，则近场复振幅可写为：

```text
E_near(x,y) = sum_k A_k(x,y) * exp(j * phi_k)
```

远场复振幅由二维傅里叶变换给出：

```text
E_far(u,v) = FFT2(E_near(x,y))
```

远场强度为：

```text
I_far(u,v) = |E_far(u,v)|^2
```

训练输入为裁剪并归一化后的单通道远场强度图，尺寸为 `160 x 160`。

### 3.3 数据集划分

七光束主数据集包含 `1024` 个干净样本，固定划分如下：

| 数据集 | 样本数 |
| --- | ---: |
| 训练集 | 716 |
| 验证集 | 153 |
| 测试集 | 155 |

双光束低维验证数据集包含 `2000` 个样本，训练/验证/测试划分为 `1400/300/300`。双光束任务用于验证仿真链路、相位编码、数据读取和物理损失实现；七光束任务用于论文主实验。

## 4. 方法

### 4.1 普通 CNN 基线

普通 CNN 基线 `SimplePhaseCNN` 由三层卷积和全连接回归头组成，输入为单通道远场强度图，输出为 `12` 维 `sin/cos` 相位编码。训练损失为预测编码与真实编码之间的均方误差：

```text
L_phase = MSE(y_pred, y_true)
```

该模型作为七光束相位反演的基础对照。

### 4.2 物理约束 CNN

物理约束 CNN 在普通相位监督损失之外增加远场一致性损失。网络输出首先被解码为六路相对相位，再与中心参考光束共同重建七光束近场复振幅。随后通过傅里叶传播得到预测远场强度 `I_pred`，并与输入远场强度 `I_input` 比较：

```text
L_farfield = MSE(I_pred, I_input)
```

总损失为：

```text
L_total = L_phase + lambda_phy * L_farfield
```

其中 `lambda_phy` 控制物理一致性损失权重。本文已比较多个权重，并在后续残差物理约束实验中发现 `lambda_phy=0.05` 当前表现最好。

### 4.3 残差网络与最佳 checkpoint 策略

初始三层 CNN 对七光束强耦合相位反演能力有限，因此本文引入 `ResidualPhaseCNN`。该网络在多层卷积特征提取中加入残差块和自适应池化，以提升多通道干涉特征表达能力。实验表明，仅使用最终 epoch 可能低估模型性能：在 50 epoch 训练中，验证 RMSE 往往先下降后回升。因此，本文采用最佳验证 RMSE checkpoint 作为模型选择依据，并同时记录最终 checkpoint 和最佳 checkpoint 的测试表现。

### 4.4 周期相位损失与自研轻量网络探索

受 Xie 等周期相位损失启发，本文实现了：

```text
L_cyclic = mean(2 - 2 * cos(phi_pred - phi_true))
```

由于本项目标签采用 `sin/cos` 编码，实际实现中通过归一化预测的 `sin/cos` 对计算相位差余弦。同时，本文尝试了自研轻量网络 `CBCPhaseLiteCNN`，包含深度可分离残差块、空间/通道门控和多尺度池化头。该模型不直接复用 MobileNetV3-Small，而是作为面向 CBC 条纹图像的探索性结构。实验结果显示，该路线当前未超过残差物理约束主线，因此在本文中作为负结果消融记录。

## 5. 实验设置

### 5.1 评价指标

相位预测误差采用周期 RMSE：

```text
e_i = atan2(sin(phi_pred_i - phi_true_i), cos(phi_pred_i - phi_true_i))
RMSE = sqrt(mean(e_i^2))
```

除相位 RMSE 和 MAE 外，本文还统计以下补偿物理指标：

- 主瓣能量占比：中心圆形主瓣区域能量 / 裁剪远场总能量。
- 旁瓣能量占比：主瓣外区域能量 / 裁剪远场总能量。
- Strehl 比：当前远场峰值强度 / 理想相干远场峰值强度。
- 合成效率：当前主瓣能量 / 理想相干主瓣能量。
- 峰值旁瓣比：远场峰值强度 / 主瓣外最大旁瓣强度。
- 补偿后残余相位 RMSE。

### 5.2 训练配置

主要训练配置如下：

| 项目 | 设置 |
| --- | --- |
| 输入图像 | `160 x 160` 单通道远场强度图 |
| 七光束输出 | 12 维 `sin/cos` 编码 |
| 优化器 | Adam |
| 学习率 | `0.001` |
| 七光束主数据集 | 1024 样本 |
| 训练/验证/测试 | `716/153/155` |
| GPU 长训练 | RTX 3060 Laptop GPU |
| 长训练 epoch | 50 |
| batch size | 64，物理约束残差网络为 32 |
| 随机种子 | `20260612` |

## 6. 实验结果与分析

### 6.1 双光束到七光束的任务难度提升

双光束任务中，普通 CNN 已可达到 `0.003742 rad` 的测试 RMSE；加入物理约束后，双光束 RMSE 为 `0.004291 rad`，但远场 MSE 降低。七光束任务显著更难：普通 CNN RMSE 增至 `1.026976 rad`，物理约束 CNN 为 `1.022686 rad`。

| 系统 | 普通 CNN RMSE(rad) | 物理约束 CNN RMSE(rad) | 说明 |
| --- | ---: | ---: | --- |
| 双光束 | 0.003742 | 0.004291 | 用于方法链路验证 |
| 七光束 | 1.026976 | 1.022686 | 论文主实验对象 |

这说明七光束远场图像中的六路相位耦合和相位非唯一性显著提高了反演难度，不能简单用双光束结果外推多路 CBC 性能。

### 6.2 七光束普通 CNN 与物理约束 CNN

首版七光束普通 CNN 和物理约束 CNN 结果如下：

| 模型 | `lambda_phy` | RMSE(rad) | MAE(rad) | far-field MSE |
| --- | ---: | ---: | ---: | ---: |
| 普通 CNN | 0 | 1.026976 | 0.819061 | `1.1935e-4` |
| 物理约束 CNN | 0.1 | 1.022686 | 0.816424 | `1.1501e-4` |

物理约束 CNN 的相位 RMSE 只小幅降低约 `0.42%`，但远场重建误差降低约 `3.64%`。这说明物理一致性损失对远场重建有直接约束作用，但在当前网络容量和数据规模下，对相位 RMSE 的提升有限。

### 6.3 鲁棒性实验

在探测器噪声实验中，`lambda_phy=0.1` 物理约束 CNN 在干净数据上略优于普通 CNN，但当 `noise >= 0.03` 时相位 RMSE 明显高于普通 CNN，说明干净数据训练得到的物理约束模型并不天然具备探测器噪声鲁棒性。

在振幅失配和位置偏移实验中，物理约束 CNN 表现更稳定。振幅失配范围 `0~0.3` 下，物理约束 CNN 的 RMSE 相比普通 CNN 降低约 `1.25%` 到 `2.39%`；位置偏移 `0~100um` 下，RMSE 降低约 `0.99%` 到 `2.36%`。

| 扰动类型 | 测试范围 | 物理约束 CNN 相对普通 CNN 的 RMSE 变化 |
| --- | --- | --- |
| 探测器噪声 | `0~0.08` | 高噪声下变差 |
| 振幅失配 | `0~0.3` | 降低约 `1.25%~2.39%` |
| 位置偏移 | `0~100um` | 降低约 `0.99%~2.36%` |

这表明物理约束对光束状态扰动具有一定泛化收益，但对探测器噪声仍需噪声增强训练或更合理的观测噪声建模。

### 6.4 相位补偿物理指标

基于普通 CNN 和首版物理约束 CNN 的相位补偿评估结果如下：

| 状态 | 主瓣能量占比 | Strehl 比 | 合成效率 | 峰值旁瓣比 | 相位 RMSE(rad) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 补偿前 | 0.359388 | 0.390687 | 0.532856 | 1.711568 | 1.774909 |
| 普通 CNN 补偿后 | 0.519307 | 0.647172 | 0.786023 | 6.557997 | 0.905907 |
| 物理约束 CNN 补偿后 | 0.521546 | 0.653564 | 0.789644 | 6.631886 | 0.894276 |
| 理想相干 | 0.650631 | 1.000000 | 1.000000 | 13.515346 | 0.000000 |

结果说明，普通 CNN 和物理约束 CNN 都能显著提升远场能量集中度。与普通 CNN 相比，首版物理约束 CNN 在主瓣能量占比、Strehl 比、合成效率和残余相位 RMSE 上均有小幅优势。需要注意的是，该补偿评估尚未纳入最新 `residual_cnn + physics loss, lambda_phy=0.05` 最优模型，后续应补齐该模型的下游物理指标。

### 6.5 残差网络与残差物理约束

快速结构消融中，`residual_cnn` 在小样本设置下优于 `simple_cnn` 和 `wide_cnn`。进一步在 RTX 3060 上进行完整数据 50 epoch 训练后，最终 epoch 测试 RMSE 为 `1.269384 rad`，不适合作为模型选择结果；但最佳验证 checkpoint 出现在 epoch 17，测试 RMSE 为 `0.992071 rad`，首次优于普通 CNN 和首版物理约束 CNN。

| 模型 | checkpoint 策略 | 测试 RMSE(rad) | 测试 MAE(rad) |
| --- | --- | ---: | ---: |
| 普通 CNN | final | 1.026976 | 0.819061 |
| 物理约束 CNN | final | 1.022686 | 0.816424 |
| `residual_cnn` | best validation | 0.992071 | 0.812456 |
| `residual_cnn + physics loss` | best validation, `lambda_phy=0.05` | 0.983128 | 待补 |

当前最优结果来自 `residual_cnn + physics loss, lambda_phy=0.05`，其最佳 checkpoint 测试 RMSE 为 `0.983128 rad`。相比普通 CNN，RMSE 降低约 `4.27%`；相比首版物理约束 CNN，降低约 `3.87%`；相比 `residual_cnn_best`，降低约 `0.90%`。这表明残差结构与物理约束之间存在一定互补性，但提升幅度仍较有限。

### 6.6 周期损失与 `cbc_lite_cnn` 负结果

为吸收 Xie 等工作的周期损失思想，本文实现了 `mse`、`cyclic` 和 `cyclic_unit` 三种相位监督损失，并在自研轻量模型 `cbc_lite_cnn` 上进行 50 epoch 对比。

| 模型 | 损失 | 参数量 | 最佳 epoch | 最佳验证 RMSE(rad) | 最佳 checkpoint 测试 RMSE(rad) |
| --- | --- | ---: | ---: | ---: | ---: |
| `cbc_lite_cnn` | `mse` | 822,636 | 10 | 1.146974 | 1.219643 |
| `cbc_lite_cnn` | `cyclic` | 822,636 | 50 | 1.175314 | 1.281704 |
| `cbc_lite_cnn` | `cyclic_unit` | 822,636 | 38 | 1.158658 | 1.255836 |

结果显示，同一结构下普通 MSE 反而优于周期损失；`cbc_lite_cnn` 三种设置均明显弱于残差物理约束路线。因此，本文当前不将 `cbc_lite_cnn` 升级为主模型，而把它作为探索性消融和负结果记录。该结果也提示：周期损失是否有效可能依赖网络结构、标签形式、数据规模和训练稳定性，后续更合理的做法是在当前最优 `residual_cnn + physics loss` 上测试周期损失，而不是同时更换模型结构和损失函数。

## 7. 讨论

### 7.1 物理约束的收益与边界

本文结果显示，物理约束在七光束任务中能够带来稳定但幅度有限的收益。首版物理约束 CNN 相比普通 CNN 只降低 `0.42%` 的相位 RMSE，但远场 MSE 和下游补偿指标均有小幅改善。残差网络加入物理约束后，当前最优 RMSE 进一步降至 `0.983128 rad`。这说明物理约束并不是简单替代监督学习，而更像对网络预测空间施加物理筛选，使模型输出更接近可解释的远场传播状态。

然而，物理约束也存在边界。探测器噪声实验表明，干净数据训练的物理约束模型在高噪声观测下可能变差。这可能是因为远场一致性损失把输入噪声也视作需要拟合的目标，从而削弱了鲁棒性。因此，若面向真实实验系统，需要引入噪声增强、图像去噪、概率观测模型或更稳健的物理损失。

### 7.2 最佳 checkpoint 的必要性

`residual_cnn` 的最终 epoch 测试 RMSE 为 `1.269384 rad`，但最佳验证 checkpoint 测试 RMSE 为 `0.992071 rad`。这一差异说明，七光束相位反演在当前数据规模下存在明显过拟合或训练波动。如果只报告最终 epoch，会低估模型真实性能；如果不固定 checkpoint 选择策略，又可能造成结果不可复现。因此，后续论文实验应统一采用验证集最优 checkpoint 或早停策略，并同时报告最终 epoch 与最佳 checkpoint 的差异。

### 7.3 与文献结果的差距

Xie 等在实验系统中报告了约 `0.076π ≈ 0.239 rad` 量级的相位误差，而本文当前七光束最佳 RMSE 为 `0.983128 rad`。两者差距较大，原因可能包括：

- 本文当前使用焦平面/远场强度图，尚未系统比较焦前或离焦图像。
- 数据集规模仅 `1024` 个样本，明显小于文献中的大规模实验采集数据。
- 当前网络结构较轻，尚未充分利用预训练、数据增强或更成熟的轻量网络设计。
- 本文使用 `sin/cos` 编码并以六路相对相位周期 RMSE 评价，指标定义与文献可能不完全一致。
- 仿真光场、归一化方式、相机位置、噪声模型和训练策略均不同。

因此，本文不应直接声称已达到文献水平，而应强调当前阶段建立了可复现实验链条，并识别出残差结构、物理约束和 checkpoint 策略的有效方向。

### 7.4 当前论文主线选择

综合当前结果，本文建议主线暂定为：

```text
七光束远场图像
-> sin/cos 相位编码
-> ResidualPhaseCNN
-> 傅里叶远场一致性损失
-> 最佳验证 checkpoint
-> 相位 RMSE 与补偿物理指标联合评价
```

`cbc_lite_cnn` 和周期损失不应作为当前主线，但其负结果有价值：它说明“文献启发”不能简单转化为结构照搬或损失替换，必须在本项目数据、标签和物理评价链条中重新验证。

## 8. 结论

本文围绕七光束相干合成相位误差反演建立了从仿真数据生成到深度学习训练、物理约束、鲁棒性评估和远场补偿指标计算的完整实验流程。双光束实验验证了方法链路的正确性，但七光束任务因六路相位耦合而显著更难。首版普通 CNN 在七光束测试集上达到 `1.026976 rad` RMSE，物理约束 CNN 小幅降至 `1.022686 rad`，并改善远场重建和补偿指标。进一步采用残差结构和最佳验证 checkpoint 后，`residual_cnn` 最佳测试 RMSE 达到 `0.992071 rad`；残差网络与物理约束结合后，当前最优结果为 `0.983128 rad`。鲁棒性实验表明，物理约束对振幅失配和位置偏移有一定泛化收益，但对探测器噪声并不天然鲁棒。自研轻量网络与周期损失实验未超过残差物理约束路线，因此作为负结果保留。

当前阶段结论是：傅里叶物理约束和残差特征提取是七光束 CBC 相位反演中值得继续推进的方向，但现有模型距离文献先进水平仍有明显差距。后续应优先补齐 `residual_cnn + physics loss` 的下游补偿指标，并在该主线上测试周期损失、学习率调度、数据增强、离焦图像输入和更大规模训练集。

## 9. 待补实验与待完善内容

1. 补齐 `residual_cnn + physics loss, lambda_phy=0.05` 的主瓣能量占比、Strehl 比、合成效率和补偿后残余相位 RMSE。
2. 在 `residual_cnn + physics loss` 上测试 `--phase-loss cyclic`，判断周期损失是否应纳入主线。
3. 用同一 checkpoint 策略重新训练并评估 `simple_cnn`，确保残差网络提升不是由 checkpoint 策略单独造成。
4. 增加离焦/焦前强度图数据，验证相机平面位置对相位反演难度的影响。
5. 扩大七光束数据集规模，测试 `1024 -> 5000 -> 10000` 样本时 RMSE 是否下降。
6. 对最新主模型做噪声增强训练，改善探测器噪声鲁棒性。
7. 补充图表编号、图注和论文格式排版。
