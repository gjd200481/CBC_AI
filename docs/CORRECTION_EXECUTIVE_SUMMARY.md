## 问题

```
旧数据（3cm/5cm/7cm）：
  焦平面图像 ≈ 焦前图像（差异 < 1e-18）
  ❌ 不是真正的多平面观测
```

## 修正

```python
# 旧代码（错误）
propagated = propagate(near_field, distance)
intensity = |FFT(propagated)|²  # ❌ 强度退化相同

# 新代码（正确）
field_with_lens = near_field * lens_phase
field_at_detector = propagate(field_with_lens, f+Δz)
intensity = |field_at_detector|²  # ✅ 真实探测强度
```
