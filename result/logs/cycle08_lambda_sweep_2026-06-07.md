# Cycle 08 物理损失权重消融实验记录

## 任务目标

测试不同物理一致性损失权重 `lambda_phy` 对训练结果的影响，比较相位 RMSE、远场重建误差和训练稳定性。

损失函数：

```text
L_total = L_phase + lambda_phy * L_farfield
```

## 实验设置

- 数据集：`main_clean_two_beam`
- 样本数：2000
- 数据划分：训练集 1400，验证集 300，测试集 300
- 模型：`SimplePhaseCNN`
- 物理模块：`TwoBeamFourierOptics`
- 训练轮数：8 epoch
- batch size：32
- learning rate：0.001
- seed：20260608
- device：CPU

## 测试权重

```text
lambda_phy = 0, 0.01, 0.05, 0.1, 0.5, 1.0
```

说明：本周期为权重筛选实验，统一使用 8 epoch。上一周期 `lambda_phy=0.1` 的 10 epoch 结果不纳入本表直接比较。

## 初步结论

在当前无噪声双光束静态数据集、8 epoch 训练设置下：

- `lambda_phy=0.01` 取得最低相位 RMSE：`0.0042908676 rad`，约 `0.24585 deg`。
- `lambda_phy=0.01` 也取得最低远场重建 MSE：`4.8161336593e-09`。
- 相比 `lambda_phy=0`，`lambda_phy=0.01` 的相位 RMSE 从 `0.0044857701 rad` 降到 `0.0042908676 rad`，有小幅提升。
- 当 `lambda_phy` 增大到 `0.05`、`0.1`、`0.5` 后，相位 RMSE 反而上升，说明物理项过强可能影响相位监督优化。
- `lambda_phy=1.0` 比 `0.5` 略好，但仍不如 `0.01`。

## 推荐设置

当前推荐将 `lambda_phy=0.01` 作为下一阶段主候选权重。

但该结论只基于干净双光束数据。后续 Cycle 09 的噪声鲁棒性实验中，需要继续比较：

- 普通 CNN。
- `lambda_phy=0.01` 物理约束 CNN。
- 必要时补充 `lambda_phy=0.1` 作为较强物理约束对照。

最终论文主模型权重应结合噪声、振幅失配、位置偏移和远场重建一致性共同确定。
