# Cycle 19：7 光束相位补偿综合效果实验

## 任务目标

本周期目标是把前两个周期的单项物理指标汇总为一套完整的 7 光束相位补偿效果评估流程。评估对象包括：

- 补偿前：真实 6 路相位扰动直接合成远场。
- 普通 CNN 补偿后：使用普通 CNN 预测相位作为补偿量，计算残余相位远场。
- 物理约束 CNN 补偿后：使用 `lambda_phy=0.1` 物理约束 CNN 预测相位作为补偿量，计算残余相位远场。
- 理想相干：外圈 6 路相位残差全为 0。

## 新增脚本

```text
train/evaluate_seven_beam_compensation_effect.py
```

该脚本复用已有 7 光束远场重建、模型加载和相位解码函数，在同一批样本上统一输出主瓣能量、旁瓣能量、Strehl 比、合成效率、峰值旁瓣比和残余相位 RMSE。

## 运行命令

```powershell
python train\evaluate_seven_beam_compensation_effect.py
```

## 指标定义

- 主瓣能量占比：中心圆形主瓣区域能量 / 裁剪远场总能量。
- 旁瓣能量占比：主瓣外区域能量 / 裁剪远场总能量。
- Strehl 比：当前远场峰值强度 / 理想相干远场峰值强度。
- 合成效率：当前主瓣能量 / 理想相干主瓣能量。
- 峰值旁瓣比：远场峰值强度 / 主瓣外最大旁瓣强度。
- 残余相位 RMSE：补偿后 6 路外圈相位残差的周期 RMSE。

## 阶段结论

普通 CNN 和物理约束 CNN 都能显著改善 7 光束相干合成效果。补偿后主瓣能量占比、Strehl 比、合成效率和峰值旁瓣比明显提高，旁瓣能量占比和残余相位 RMSE 明显降低。

与普通 CNN 相比，`lambda_phy=0.1` 物理约束 CNN 在本实验中保持小幅优势：主瓣能量占比从 `0.519307` 提高到 `0.521546`，Strehl 比从 `0.647172` 提高到 `0.653564`，合成效率从 `0.786023` 提高到 `0.789644`，残余相位 RMSE 从 `0.905907 rad` 降至 `0.894276 rad`。

该结果可以作为论文中“相位误差反演结果能够用于实际补偿控制，并提升远场能量集中度”的核心支撑之一。
